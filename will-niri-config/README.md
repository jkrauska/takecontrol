#Will's Niri Config File
This is my Niri config, there are many like it, but this one is mine. 

These files are designed to live in my ~/.config/niri folder and work with Noctalia v5. The generic options that apply on all the PCs I use are in the config.kdl file, while machine-specific options are in window-rules.kdl and monitors.kdl. (I'm not sure what the noctalia.kdl file is for). To sync them with git, I add the monitors.kdl and window-rules.kdl to my .ignore list.
